# Security Policy

## Supported Versions

InstaMealie is a single-version application (not a library), and only the latest
commit on `main` is supported with security fixes. Older releases are not
maintained.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately via GitHub's security advisory flow:

<https://github.com/TomGrozev/insta-mealie/security/advisories/new>

You will receive an acknowledgement, and we will coordinate disclosure and a
fix before any public mention.
